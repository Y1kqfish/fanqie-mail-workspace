## 性能验收入口

扩展自有 shell 的 `data-fqmail-perf` 提供当前文档内最近三条样本，样本字段只有 `operation`、`count`、`seq`、`domMs`、`ms`、`valid`：

- `catalog-first`：首次完整目录行构建；
- `catalog-resync`：已有行节点的重同步/更新；
- `catalog-search`：搜索事件至下一可绘制帧机会；
- `catalog-filter`：筛选事件至下一可绘制帧机会。

计时使用 `performance.now()` 和可取消的两阶段 `requestAnimationFrame`。`domMs` 从元数据可用/操作开始到 DOM 提交结束；`ms` 延伸到跨过一次绘制机会后的下一帧回调。两者都不是精确 GPU 呈现时间。后台/不可见文档、取消、销毁、过期回调和失败样本为 `valid:false` 且数值字段为 `null`。计时不影响阅读、目录、导航或筛选。

本批不要求用户再次重载或采集计时。若后续批次重新获得用户批准并需要量化，才在手动重载后仅用 Browser/Chrome 采集：首次目录 3 次、搜索 3 次、筛选 3 次。每次记录 Chrome 版本、`N`、viewport、各次有效 `ms` 与最大值；不计用户打开/关闭原生目录的等待时间。首个失败立即停止，并把非敏感结果带回主任务。

## 会话清理语义

- 当前默认路线是用户真实点击番茄阅读页原生目录；官方作品页采集仅由用户明确调用 `startFallback` 的回退入口启动。`catalog-page-source.js` 与旧 handoff 模块不在 Manifest 加载链；`catalog-page-workflow.js` 仍加载用于显式作品页回退，其遗留 `load`/静默分支不走当前默认原生同步路线。旧 handoff 测试不是现行实机证据，默认路径不会自动创建隐藏 iframe。
- 章节身份不匹配时，当前页不渲染旧目录；不会仅因一次 mismatch 主动删除后台会话记录。新书成功同步后替换当前标签页的会话目录。
- 标签页关闭、停用、浏览器重启或扩展重载时清理 `storage.session` 目录元数据；不会主动删除 `storage.local` 中的已读状态或阅读进度。
