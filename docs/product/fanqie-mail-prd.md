# 番茄 Mail 产品需求文档

状态：M0 产品基线，2026-08-29

当前实施状态：M3.0/M3.1 章节工作流已完成本地实现与自动验证，M4.2 Chrome 核心流程与 M4.3 核心手工检查已由用户确认；个人 M4.4 候选包已生成但实际安装冒烟尚待用户完成，真实性能尚未量化但经用户接受不再阻塞阶段交接。

## 产品目标

番茄 Mail 是仅供个人使用的 Chrome/Edge 阅读页扩展。它把当前番茄小说阅读页映射为高保真的 Outlook 式工作区，让用户在熟悉的邮件信息架构中完成章节浏览、筛选、搜索、阅读和恢复原页面，同时保留番茄原生正文、字体和导航行为。

产品不是邮箱客户端，不连接真实邮箱，也不复制 Outlook 的无效装饰或番茄的未公开能力。

## 目标用户与核心任务

目标用户是已经在番茄官网阅读当前书籍、希望使用低干扰桌面工作区的个人用户。

核心任务按优先级排列：

1. 在不复制正文的前提下稳定显示当前章节。
2. 通过“同步邮件”读取当前阅读页由番茄原生目录渲染的章节链接，并在章节列表中浏览和选择章节；仅在原生同步失败且用户明确触发时，才使用官方作品页回退。
3. 使用上一封、下一封、当前、未读、已读等邮箱语义完成章节导航。
4. 按章节标题搜索已加载目录，不搜索正文。
5. 随时恢复番茄原生页面，且不遗留空白、重复外壳或错误滚动位置。

## 产品原则

- 原生优先：正文、动态字体、目录条目和章节导航都使用番茄当前页面已经渲染的节点。
- 功能真实：核心搜索和章节筛选必须有真实作用；展示型按钮、非核心文件夹和设置要明确标注为展示，不伪装成邮箱业务。
- Outlook 高保真映射：复用当前 Outlook 的信息架构、尺寸层级和 Fluent 视觉，不做像素级或业务级克隆。
- 权限克制：只声明 `storage`；不增加网络、主机、Cookie、历史记录或正文访问能力。
- 可逆接管：任何停用或恢复操作最终都必须返回可阅读的番茄原生页面。
- 证据分层：自动测试、静态扫描和真实浏览器验收分别报告，不能相互替代。

## 信息架构与语义映射

| Outlook 区域 | 番茄 Mail 语义 | 行为 |
| --- | --- | --- |
| 顶部蓝色栏 | 产品标识与章节搜索 | 只搜索已加载的章节标题 |
| 应用轨 | 章节工作区入口 | 仅保留真实可用入口 |
| 文件夹树 | 全部、当前、未读、已读 | 对当前书籍目录进行状态筛选 |
| 邮件列表 | 章节列表 | 显示标题、当前状态和已读状态 |
| 阅读窗格 | 番茄原生阅读盒子 | 保留同一 DOM 节点和动态字体 |
| 命令栏 | 上一封、下一封、同步邮件、恢复番茄 | 章节同步、导航或恢复 |

本版本只服务当前书籍，不建立本地多书库。筛选项、搜索词和目录元数据是当前页面会话状态；已读状态、阅读进度和启停设置继续本地持久化。完整章节导航使用按标签页隔离的 `storage.session` 保存受限公开章节元数据，目标页可重复恢复；章节身份不匹配时不显示旧目录，同一本书的新一轮成功同步会替换当前会话记录。标签页关闭、停用、浏览器重启或扩展重载时清理会话元数据，但不主动删除本地已读状态或阅读进度，不构成长期目录缓存。

## 范围

### 包含

- 精确匹配 `https://fanqienovel.com/reader/*`。
- 当前书籍和章节身份解析。
- 原生正文的可逆搬运与滚动进度。
- 原生阅读页目录同步：用户明确点击番茄原生目录后读取当前页目录；失败后才允许用户明确打开官方作品页回退。
- 完整章节目录、章节选择、active/visited 与本地已读状态。
- 上一章/下一章代理。
- 全部、当前、未读、已读筛选。
- 已加载章节标题搜索。
- Outlook 高保真桌面布局和窄屏安全降级。
- Chrome 与 Edge 手工验收。

### 不包含

- 真实邮箱、联系人、日历、邮件发送或 Microsoft 账号集成。
- 多书库、书架同步或跨设备同步。
- 正文搜索、正文复制、正文缓存、批量抓取或离线阅读。
- 番茄隐藏接口、URL 猜测或自行构造章节请求。
- 评论、书签、删除、下载、奖励或广告功能。
- 移动端 Outlook 复刻。

## 关键工作流

### 启动与阅读

扩展只在有效阅读页启动。外壳挂载后，右侧显示同一个 `.muye-reader-box`；如果挂载失败，不显示伪成功状态。保存的章节进度恢复到皮肤实际滚动窗格。

整页章节导航的新文档在 `document_start` 显示一次轻量加载过渡，主 controller 仍在 `document_idle` 挂载完整工作区。启用设置读取失败、停用、恢复、启动异常或 5 秒硬上限到达时释放过渡；它不复制正文、不搬运原生 reader box，也不介入原生目录同步。

启用工作区后，当前阅读标签使用固定标题“收件箱 - Outlook”和本地打包的官方 Outlook 彩色 favicon。标签外观在当前文档内存中跟踪站点后续 title/favicon 变化，停用或恢复时删除自有节点并恢复最新原生状态；不读取账户或其他标签页信息。

### 同步目录

邮箱命令栏显示“同步邮件”。点击后暂时隐藏邮箱外壳，提示用户点击番茄原生“目录”；扩展观察 `#app` 与页面 body 中实际出现的 `.reader-catalog .chapter[data-item-id]`，目录关闭后再一次性恢复外壳并渲染。同步失败不清空当前章节邮件；只有用户明确点击“打开作品页同步”才使用一次性 token 进入官方作品页回退，默认路径不创建隐藏 iframe。选择章节时只使用经校验的同源 `/reader/<id>` 链接进行整页导航，扩展只交接受限的章节元数据，并按当前标签页在新页重复恢复。

### 筛选与搜索（M3.1）

目录 ready 后，搜索只匹配规范化章节标题；收件箱、当前、未读、已读文件夹映射到章节状态。首次最多一次提交完整行集合，后续搜索/筛选复用行节点并切换可见性，不读取正文。

### 导航与恢复

上一封、下一封沿用真实原生节点；目录章节选择使用经过来源、origin、路径和数字 ID 校验的同源 `/reader/<id>` 链接进行整页导航，不猜章节来源、不读正文。章节变化前保存旧进度，变化后重新识别身份和正文节点。恢复时优先精确放回原节点；原占位符已被 SPA 替换时，先持久化停用状态，再刷新当前 URL 让番茄重建页面。

## 成功指标

指标在参考页面 `https://fanqienovel.com/reader/7504850255494529561` 上验收，章节数量始终以真实 DOM 为准。

- 目录：一次真实用户点击后，5 秒内进入成功或明确错误状态；参考页面出现的完整目录不得截断。
- 目录性能：`catalog-first` 与 `catalog-resync` 分别记录从元数据可用到 DOM 提交结束的 `domMs`，以及跨过一次绘制机会后的 `ms` 估计；搜索和筛选也分别记录至跨绘制帧机会。`requestAnimationFrame` 不是精确 GPU 呈现证据。目标仍为目录 <=1 秒、搜索/筛选 <=100ms，三次真实 Chrome 样本尚未采集。
- 搜索与筛选：属于 M3.1，仅匹配已加载章节标题；Chrome 功能手工结果已记录，性能量化本批未验证且不再阻塞交接。
- 导航：上一封/下一封成功时身份发生变化，失败时 1.5 秒内显示“章节切换未生效”。
- 恢复：恢复后必须看到原生正文；精确恢复失败时只允许一次当前页面刷新兜底。
- UI：2560px 基线呈现完整七区结构；1920px 以上保留 305px 右侧工具区，1280–1919px 收为 48px 工具轨，960–1279px 隐藏右侧并压缩导航/列表，720–959px 隐藏应用轨与文件夹树保留列表/正文双栏，小于 720px 列表与正文纵向排列。
- 安全：Manifest 只含 `storage`，静态扫描无 `host_permissions`、`fetch`、`XMLHttpRequest`、`WebSocket`、正文复制或正文缓存。
- 质量：自动测试全绿；Chrome 和 Edge 的真实页面验收单独通过。
