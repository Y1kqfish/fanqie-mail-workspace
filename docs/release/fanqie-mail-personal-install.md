# 番茄 Mail 个人候选包安装与使用说明

这是仅供个人本地使用的 Chrome/Edge Manifest V3 候选包，版本保持 `0.1.0`。默认只作用于 `https://fanqienovel.com/reader/*`；作品页仅在阅读页原生同步失败且用户明确触发回退时，由最小 page collector 采集受限章节元数据。不连接真实邮箱、不建立服务器、不读取账户、Cookie 或浏览历史。

## 安装

1. 将 ZIP 解压到一个固定目录。
2. 打开 Chrome 的 `chrome://extensions`，或 Edge 的 `edge://extensions`。
3. 打开“开发者模式”，选择“加载已解压的扩展”，选中解压后的目录（该目录根部必须直接包含 `manifest.json`）。
4. ZIP 文件不能直接加载；加载后不要移动、删除或重命名解压目录。

已有 `D:\番茄` 的加载实例可以继续使用，无需卸载旧扩展，也不要清除数据。若要测试本候选 ZIP，先停用旧扩展，避免两个实例同时注入；不同加载路径可能产生不同扩展 ID 和独立存储，不承诺自动迁移。

## 使用与恢复

- 在番茄官方阅读页启用皮肤后，使用 Outlook 式章节列表、搜索、筛选、上一封/下一封和“同步邮件”。目录同步要求用户点击番茄原生目录；作品页回退只有在原生同步失败后由用户明确触发。
- `Alt+Shift+M` 可切换皮肤；“更多 → 恢复番茄”会移除外壳并恢复原生阅读页。若 SPA 替换导致无法精确放回，扩展会先停用并刷新当前页面，让番茄重建原生阅读器。
- 展示型命令不会连接邮箱、导航或写入业务数据；搜索只匹配已加载章节标题，不搜索正文。
- 扩展重载、浏览器重启或停用后，目录会话元数据需要重新同步；已读状态和阅读进度不会被主动删除。

## 已知限制

- 本候选包不是 CRX，不签名、不上传，也没有对外分发授权声明；默认用途是个人本地安装。
- M3 性能阈值尚未量化；无匹配搜索的空态提示仍是已接受的非阻断限制。
- M4.3 的精确 2560/1920/1280/960/720/375 断点、全部隐藏行键盘焦点、真实慢加载和启动失败恢复仍未完成完整矩阵验收。
- Chrome/Edge 核心流程已有用户手工记录，但候选包本身尚未由用户完成解压安装冒烟；自动测试和 ZIP 内容核验不等同于浏览器安装通过。
