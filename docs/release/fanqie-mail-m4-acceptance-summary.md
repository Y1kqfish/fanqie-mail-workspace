# 番茄 Mail M4 候选包验收摘要

本摘要随个人使用候选 ZIP 分发，仅记录证据边界，不把自动检查或用户反馈扩大为完整浏览器通过。

## 阶段状态

| 阶段 | 状态 | 证据边界 |
| --- | --- | --- |
| M3.0/M3.1 | 功能手工验收完成 | 性能量化未验证，经用户接受不再阻塞阶段交接 |
| M4.2 Chrome 核心流程 | 用户手工确认通过 | 版本、章节数量、viewport、截图和正文 DOM 单份计数未采集 |
| M4.3 兼容性 | 核心手工检查完成 | 精确断点、全部隐藏行焦点、慢加载和启动失败恢复仍待验证 |
| M4.4 个人候选包 | 内容候选已生成 | 用户实际解压、加载和安装冒烟尚待完成；不对外发布 |

## 已记录的手工结果

- Chrome：刷新进度、快捷键、停用/启用、恢复番茄、目录同步与选章、上一封/下一封、章节搜索、清空搜索、当前/未读/已读筛选及再次同步后取消均由用户确认正常。
- Chrome 窄屏：列表与正文可上下排列，正文滚动、选章、上下章、更多和恢复仍可用；精确 viewport 未测。
- Edge：邮箱启动、正文、同步目录、选章、上下章、刷新进度/目录保留、恢复和快捷键重新启用由用户确认正常；不代表完整 Edge 矩阵通过。
- 一次“同步邮件但不点击原生目录”的约 30 秒结果显示受控返回并提示原生目录未打开；该项浏览器未注明，不能默认为 Chrome/Edge 双通过。

## 本地与安装边界

- 本地自动测试、语法、Manifest、静态扫描和 ZIP 内容哈希只能证明候选包完整性，不能证明真实浏览器安装或页面功能通过。
- Chrome 首次 `claimTab` 20 秒超时保留为历史浏览器工具连接阻塞，不代表当前 M4.2 功能暂停。
- M3 性能量化与无匹配空态提示保持已接受的非阻断结论；M4.3 残余矩阵和 M4.4 用户安装冒烟需独立确认。
