# 番茄 Mail Outlook 截图级复刻设计

## 目标

以用户提供的 2560×1305 Outlook Web 截图和同一真实 Outlook 页面的只读几何审计为唯一视觉基线，重写番茄 Mail 皮肤。目标不再是“Outlook 风格”，而是让顶栏、应用轨、功能区、文件夹树、邮件列表、阅读邮件卡片、右侧广告区和底部任务标签在第一眼及逐区对照时均接近 Outlook Web。

本设计只复刻界面结构、图标、状态与低风险视觉交互，不连接真实邮箱，不读取或保存 Outlook 邮件、账户、Cookie 或浏览历史。番茄目录继续冻结。

## 根因与边界

当前实现失败的根因不是单个尺寸，而是组件体系不完整：

- 功能区只有一排普通按钮，缺少 Outlook 的标签行、圆角命令容器、分裂按钮、下拉段、分隔线和溢出按钮。
- 图标虽来自 Fluent，但数量和语义不足，仍存在通用图标复用，无法形成 Outlook 的视觉识别度。
- 文件夹树、邮件列表和阅读区只是语义映射，没有复制截图中的控件密度、头像、复选框、时间、工具按钮与白色邮件卡片。
- 右侧区域被实现为自定义卡片，而截图中是 305px 广告/占位区域。
- 缺少底部 41px 任务标签栏。
- 上一章、下一章、恢复等产品操作以自定义文字暴露在功能区，破坏 Outlook 原始命令结构。

禁止用整张截图作为背景图或热点图。该方案虽然静态相似，但会破坏响应式、可访问性、正文滚动和动态内容。所有视觉元素必须由可测试的 DOM、CSS 和本地 SVG 组成。

## 页面结构

### 顶栏

- 48×48 九宫格应用启动器。
- 168px 左侧品牌区域，显示 Outlook 字标。
- 350×32 搜索框，仅视觉展示；输入不触发章节或正文搜索。
- 右侧依次显示反馈、购买 Microsoft 365、通知、设置和本地圆形头像占位。
- 不显示用户真实姓名、邮箱或 Microsoft 账户状态。

### 应用轨

- 40×40 图标按钮按 46px 步距排列。
- 邮件使用选中态；日历、人员、待办及 Office 装饰入口使用各自的本地图标与颜色。
- 所有非邮件入口只产生短暂展示提示，不导航、不读写数据。
- 底部显示“更多应用”九宫格按钮。

### 标签与功能区

第一行复制导航按钮、“文件 / 主页 / 查看 / 帮助”标签，主页为默认选中态。

第二行必须按 Outlook 的按钮宽度和图标语义渲染：

| 命令 | 图标 | 桌面宽度 |
| --- | --- | ---: |
| 新邮件 | `ComposeRegular` | 91px + 24px 下拉段 |
| 删除 | `DeleteRegular` | 60px + 24px 下拉段 |
| 存档 | `ArchiveRegular` | 64px |
| 报告 | `ShieldErrorRegular` | 60px + 24px 下拉段 |
| 移至 | `FolderArrowRightRegular` | 78px + 下拉符号 |
| 全部答复 | `ArrowReplyAllRegular` | 88px + 24px 下拉段 |
| 已读/未读 | `MailReadRegular` | 97px |
| 标记/取消标记 | `FlagRegular` | 121px + 24px 下拉段 |
| 应用 | `AppFolderRegular` | 32px |
| 发现组 | `PeopleCommunityRegular` | 78px |
| 撤消 | `ArrowUndoRegular` | 64px，禁用视觉态 |
| 更多 | `MoreHorizontalRegular` | 32px |

下拉段独立承载 `ChevronDownRegular`，分裂按钮具有共享边框和各自 hover/pressed 状态。无番茄映射的命令只显示展示提示。

上一章和下一章不再以“上一封/下一封”文字插入该功能区。它们映射到邮件列表标题行中的上一项/下一项图标。恢复番茄和停用皮肤放入“更多”弹出菜单，保留 `Alt+Shift+M`。

### 文件夹树

- 顶部收藏夹组、折叠箭头和收藏夹标题。
- 当前书名映射为第二个账户/文件夹组标题，不伪造邮箱地址。
- 收件箱、已发送邮件、草稿、垃圾邮件、已删除邮件、便笺、存档、对话历史记录、转到组分别使用独立 Fluent 图标。
- 收件箱使用 Outlook 蓝色选中背景并聚焦当前章节邮件。
- 未提供真实数据的数字计数不显示；不得复制截图中的用户邮件数量。

### 邮件列表

- 顶部显示“重点 / 其他”选项卡、选择、排序和列表控制图标。
- 只渲染一条真实当前章节邮件，不制造其他章节。
- 当前行包括复选框、圆形头像、发送者“番茄小说”、真实章节标题、当前时间/阅读状态和选中背景。
- 邮件行高度、左右内边距、头像、文本基线和图标位置按截图重建。

### 阅读邮件卡片

- 阅读区背景为 `#f5f5f5`，正文承载在白色邮件卡片中。
- 顶部有独立主题条；主题来自真实章节标题。
- 邮件卡片包含本地头像、发送者“番茄小说”、本地阅读说明、日期占位、答复、全部答复、转发、应用和更多图标。
- 原生 `.muye-reader-box` 保持唯一节点并搬入邮件正文容器，不提取 `textContent`，不复制正文。
- 在皮肤作用域内隐藏原生重复章节标题/元数据，只调整背景、边距和容器外观，不改变正文动态字体。
- 阅读窗格仍是实际滚动与进度容器，恢复番茄时原生节点精确归位。

### 右侧广告区域

- 固定 305px，背景 `#f5f5f5`。
- 使用本地 Outlook 标志占位图标、广告说明和“广告”标签，复刻截图构图；不加载真实广告或远程资源。
- 不再显示日历、待办和提示卡片。

### 底部任务标签栏

- 阅读区底部固定 41px 浅灰标签栏。
- 显示一个收件箱标签、一个回复草稿视觉标签和一个当前章节选中标签；全部文案由当前书名/章节标题裁切生成，不创建假章节。
- 关闭、编辑和选中状态使用 Fluent 图标；装饰标签不改变数据。

## 图标体系

采用 Microsoft 官方 `microsoft/fluentui-system-icons` 的本地 SVG 资产。官方命名规则为 `[name]_[size]_[style]`，普通图标使用 20px regular/filled，应用轨可在官方存在时使用 color 变体。来源说明见 [Fluent UI System Icons](https://github.com/microsoft/fluentui-system-icons) 和 [SVG 包说明](https://github.com/microsoft/fluentui-system-icons/tree/main/packages/svg-icons)。

实现要求：

- 建立语义图标注册表，不允许业务组件直接使用不相干的占位图标。
- 常规命令使用 20px，应用轨使用 20–24px，12px 下拉箭头独立注册。
- selected 状态使用 filled 变体，默认状态使用 regular 变体。
- 所有路径固定到现有批准提交 `4d685f77b2cb8f3f412a74ec8d920c8c91149528`，记录每个上游文件路径和 MIT 许可。
- 禁止运行时 CDN、字体图标、base64 远程资源和复制 Outlook 页面内部 SVG/path。
- Office 产品装饰入口只有在固定官方资产存在时才使用品牌色 SVG；否则使用 Fluent 通用应用图标，不自行伪造微软产品 Logo。

至少覆盖：应用启动器、搜索、反馈、钻石/Microsoft 365、通知、设置、头像、导航、邮件、日历、人员、待办、新建、删除、存档、报告、移动、答复、全部答复、转发、已读、旗标、应用、群组、撤消、更多、文件夹折叠、收件箱、发送、草稿、垃圾邮件、便笺、复选框、头像、排序、置顶、关闭和编辑。

## 代码边界

皮肤拆分为：

- `fluent-icons.js`：固定来源 SVG 注册表和可访问 SVG 构造。
- `components.js`：图标按钮、分裂按钮、标签、文件夹行、邮件行、菜单和任务标签等无业务组件。
- `index.js`：组合页面并将现有真实回调映射到指定控件。
- `styles.css`：唯一视觉来源，全部选择器保持 `fqmail-` 前缀。

保持 `Fqmail.outlook.create()` 对 controller 的现有接口。新增皮肤内部接口：

```js
skin.showPresentationNotice(message)
skin.openMoreMenu()
skin.closeMoreMenu()
skin.focusCurrentMessage()
```

主 controller 不接收展示按钮回调，不新增邮箱概念，不恢复目录。

## 交互与可访问性

- 展示按钮可点击、可获得键盘焦点，具有真实 hover、pressed、tooltip 和菜单展开状态。
- 展示点击只显示 1200ms 非阻塞提示，并恢复此前真实运行状态。
- 分裂按钮的主段和下拉段均不得触发外部副作用。
- 图标按钮保留视觉隐藏文本或 `aria-label`。
- 弹出菜单支持 Escape 关闭、点击外部关闭和焦点返回。
- 禁用态（例如撤消）使用真实 `disabled`，不伪装成可操作按钮。

## 测试与验收

自动测试必须先 RED 后 GREEN：

- 页面八个区域单实例，DOM 顺序与截图一致。
- 功能区命令、宽度、分裂按钮段、分隔线和图标语义逐项匹配清单。
- 至少 35 个语义图标，禁止同一个通用图标替代不同命令。
- 当前章节邮件始终只有一条，标题和 chapterId 来自真实 snapshot。
- 上下章、恢复、停用各只触发一次；展示控件对 controller、storage、目录和 URL 零副作用。
- More 菜单承担恢复与停用入口并满足焦点/关闭行为。
- 原生 reader box 单节点、动态字体、进度和恢复测试不回归。
- 目录运行时默认停用且界面无目录按钮、目录数量或章节筛选。
- Manifest 仍仅 `storage`、精确 `https://fanqienovel.com/reader/*`、无 `host_permissions`。
- 静态扫描无网络调用、正文复制/缓存、`innerHTML` 和宽泛 CSS。

真实 Chrome 验收分三关：

1. **顶栏与功能区：** 对照截图检查所有图标、宽度、分裂按钮和状态，任一占位图标即失败。
2. **邮件工作区：** 检查文件夹树、单邮件行、白色阅读卡片、305px 广告区和 41px 底部标签栏。
3. **真实功能：** 检查上下章、More 菜单恢复、停用、快捷键、正文滚动、进度和可逆恢复。

每关在 2560×1305 输出番茄页面截图和尺寸表。不得保存包含 Outlook 邮件或账户内容的基线截图到仓库。Browser/Chrome 无法完成时由用户手动操作，自动测试不得替代实机证据。

## 非目标

- 不恢复番茄目录。
- 不实现真实邮件发送、删除、存档、报告、移动、回复或搜索。
- 不连接 Microsoft 365 或番茄隐藏接口。
- 不读取、持久化或转发 Outlook 页面数据。
- 不保证复刻 Outlook 移动版；窄屏只要求安全可用。
